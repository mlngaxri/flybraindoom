## Flappy-style benchmark environment

The game environment, physics, replacement artwork and reinforcement integration are original code in this repository. The benchmark is inspired by the one-button obstacle-passing structure popularised by Flappy Bird, but this repository does not redistribute original Flappy Bird source code, sprites, audio or other proprietary assets.
